How to Extract & Run

Option 1: Windows App (InventoryManagementSystem-Windows.zip)

  1. Click Download Windows App (.zip) above.
  2. Right-click the ZIP file and select Extract All...
  3. Open the extracted folder and double-click InventoryManagementSystem.exe.
  4. The app automatically initializes InventoryManagementDB on SQL Server LocalDB or SQLEXPRESS.

Option 2: Source Project (InventoryManagementSystem-Source.zip)

  1. Click Download Source Code (.zip) above.
  2. Extract the ZIP archive to any folder.
  3. Open InventoryManagementSystem.sln in Visual Studio Community 2022+.
  4. Press F5 to restore NuGet packages and run the desktop application.
